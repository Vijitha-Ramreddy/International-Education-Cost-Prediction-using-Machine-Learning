International Education Cost Prediction Using Machine Learning

This project predicts the total cost of studying abroad based on factors such as country, city, university, program, education level, course duration, living cost, visa fees, and insurance costs.

The project includes data cleaning, exploratory data analysis (EDA), feature engineering, preprocessing, feature scaling, and regression modeling. Multiple machine learning models are trained and evaluated using performance metrics to compare their results and identify the best-performing model.

Technologies Used
Python
NumPy
Pandas
Matplotlib
Seaborn
Scikit-learn
Machine Learning Models

Linear Regression, Ridge, Lasso, ElasticNet, Decision Tree, Random Forest, AdaBoost, KNN, SVR, Bagging, and Stacking Regressor.
